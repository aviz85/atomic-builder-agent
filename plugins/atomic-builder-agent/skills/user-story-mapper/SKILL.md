# User Story Mapper

Use this skill after Layer 2 is partially stable.

## Pattern

As the business owner, I want the agent to ___, so that ___.

## For Each Story Classify

- Required knowledge.
- Required tool.
- Required skill.
- Human approval point.
- Expected output.
- Failure mode.

## Ranking

Rank by:

1. Business value.
2. Feasibility today.
3. Context readiness.

## Output

Write or update `data/user-stories.md`.
