# AGENTS.md Writer

Use this skill to write the project instruction file for the student's agentic app.

`AGENTS.md` is the orientation layer. It is not a dumping ground. It tells the agent where it is, what matters, how to work, what not to do, and where to find knowledge.

## Required Sections

1. Project identity.
2. Business context.
3. Primary goal.
4. Folder map.
5. Operating rules.
6. Approval rules.
7. Tools and integrations.
8. Skills available.
9. Current priorities.
10. Open loops.

## Quality Bar

A new Codex session should be able to read `AGENTS.md` and understand:

- what project this is
- what the agent is allowed to do
- what information exists
- what must not be guessed
- what the next action is

## Output

Draft or update the project `AGENTS.md`.
