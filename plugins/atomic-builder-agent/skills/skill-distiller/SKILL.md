# Skill Distiller

Use this skill when a workflow was performed manually and should become repeatable.

## Trigger Signals

- The student says: "I will need this again."
- The agent keeps making the same mistake.
- A manual process succeeded twice.
- The student says: "TSK" or asks to improve the process.

## Process

1. Capture the successful path.
2. Remove one-off details.
3. Define when to use it.
4. Define inputs.
5. Define outputs.
6. Define safety rules.
7. Save as a skill draft.

## Output

Draft a new skill under `skills/<skill-name>/SKILL.md` or update `data/skill-catalog.md`.
