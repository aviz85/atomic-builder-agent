# Agentic App Architect

Use this skill to define the student's first agentic application.

## Definition

An agentic app is not a normal app.

- The agent is the runtime.
- Documents replace algorithms.
- Skills replace libraries.
- Commands replace API endpoints.
- Markdown/JSON files replace the database.
- Routines replace background jobs.
- Chat/terminal is the first UI.

## Questions

1. What project are we building around?
2. Who uses this agentic app?
3. What business state must it remember?
4. What questions should it always be able to answer?
5. What recurring workflows should it perform?
6. What commands should exist?
7. What files represent the app's state?
8. What tools or integrations does it need?
9. What actions require human approval?
10. What does success look like after one week?

## Output

Create or update `data/project-spec.md` with:

- App name.
- Purpose.
- Users.
- State files.
- Commands.
- Skills.
- Integrations.
- Human approval gates.
- First demo workflow.
- Success test.
