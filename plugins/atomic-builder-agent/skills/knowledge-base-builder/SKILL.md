# Knowledge Base Builder

Use this skill to build Layer 2.

The goal: the agent should answer important questions about the project without guessing.

## Process

1. List what the agent already knows.
2. List what the agent must know.
3. Identify missing documents.
4. Ask the student to paste, upload, or create those documents.
5. Create a knowledge map.
6. Define test questions.

## Knowledge Categories

- Business overview.
- Customers.
- Offers.
- Pricing.
- Process.
- Past examples.
- Constraints.
- Tone of voice.
- Decision rules.
- Red lines.
- Current open loops.

## Output

Write `data/knowledge-map.md`:

- Known.
- Missing.
- Must create today.
- Can create later.
- Questions the agent should now answer.
