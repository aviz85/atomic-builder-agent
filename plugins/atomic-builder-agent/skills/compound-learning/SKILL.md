# Compound Learning

Use this skill at the end of every substantial session.

## Ask

1. Should this become permanent knowledge?
2. Should this become a skill?
3. Should this become a routine later?
4. Did we discover a missing tool?
5. What open loop must not be lost?

## Output

Update as needed:

- `data/knowledge-map.md`
- `data/skill-catalog.md`
- `data/routine-plan.md`
- `data/open-loops.md`
