# Codex Operation

Use this skill for Layer 1: operating Codex as the agent nucleus.

## Teach

- Open Codex from the project folder.
- Keep project instructions in `AGENTS.md`.
- Keep work inside a clear folder.
- Use small prompts and inspect results.
- Use commands for repeated flows.
- Use skills for reusable processes.
- Use `codex exec` or the Codex SDK later for headless routines.

## Diagnose

Check whether the student can:

1. Open Codex in the correct folder.
2. Explain what the agent can see.
3. Tell the agent what not to do.
4. Use `AGENTS.md` as project orientation.
5. Understand that the agent is the runtime of the agentic app.

## Output

Write or update `data/codex-setup-checklist.md`.
