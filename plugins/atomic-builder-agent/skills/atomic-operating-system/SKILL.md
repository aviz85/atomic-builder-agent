# Atomic Operating System

Use this skill when the student has multiple workflows and wants to connect them into a business operating system.

## Map

1. Business functions: sales, marketing, service, finance, operations, content.
2. Agent roles for each function.
3. Data handoffs between agents.
4. Human approval points.
5. Dashboards and briefs.
6. Metrics.
7. Current bottlenecks.
8. 30/60/90-day plan.

## Output

Write `data/atomic-operating-map.md` with:

- Agent roster.
- Handoff protocols.
- Approval matrix.
- Business dashboard concept.
- Next 30 days.
