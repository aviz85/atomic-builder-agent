# Approval Gate Designer

Use this skill before any workflow becomes semi-automatic or scheduled.

- Draft only.
- Ask before send.
- Ask before publish.
- Ask before delete.
- Ask before spend.
- Ask before connect.
- Ask before schedule.
- Ask before deploy.
